# Repository workflow

- Start work on a new branch from `main`. Do not commit or push directly to
  `main`.
- Open a pull request into `main` and resolve every review conversation before
  merging.
- Keep `main` linear: use squash or rebase merge. Never force-push or delete
  `main`.
- Follow [the contributor guide](CONTRIBUTING.md) for checks before
  opening a pull request.
